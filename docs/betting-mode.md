# 馬券風 次単語予想モード（裏モード）

高校生向けの展示ではなく、**大学生・教員向けの裏モード**です。
LLM が次の単語を決めるまでの過程を競馬に見立てて、上位3語を当てます。

```
プロンプト「今日は」   ──▶  1つのレース
候補の単語            ──▶  出走馬
最終出力の確率順       ──▶  着順（＝正解）
途中の層での確率       ──▶  レース中の位置取り
層の深さ              ──▶  走った距離（1層 = 100m）
```

**その場で推論はしません。** ノートブックで確率を計算して CSV にし、
アプリに取り込んでからオッズを調整する、という事前作成のワークフローです。
ノートブックは**ローカルでも Colab でも動きます。GPU は要りません**
（手順は [notebooks/README.md](../notebooks/README.md)）。

## ゲームのルール

| 項目 | 既定値 | 備考 |
| --- | --- | --- |
| 所持金 | 100,000 円 | 設定で変更可 |
| レース数 | 5 | 設定で変更可 |
| 1レースの投票上限 | 所持金の全額 | 分割して複数の券種に賭けられる |
| ゲームオーバー | 所持金 0 円 | 残りレースがあっても終了 |

**「一回あたりの予算は10万円」は、1プレイの初期所持金 10 万円**と解釈しています。
各レースで 10 万円が補充されるわけではありません（それだと所持金 0 が起きず、
「お金がなくなったらゲームオーバー」が成立しないため）。
補充式にしたい場合は `refillPerRace` を true にすると各レース開始時に初期額へ戻ります。

### 券種

8 種類すべてに対応します。**着順は最終出力確率の降順**で、1着＝最も確率の高い語です。

| 券種 | 的中条件 | 控除率 |
| --- | --- | --- |
| 単勝 | 1着を当てる | 20.0% |
| 複勝 | 3着以内に入る馬を当てる | 20.0% |
| 枠連 | 1・2着の**枠**の組み合わせ（順不同） | 22.5% |
| 馬連 | 1・2着の組み合わせ（順不同） | 22.5% |
| ワイド | 選んだ2頭がともに3着以内 | 22.5% |
| 馬単 | 1・2着を着順どおり | 22.5% |
| 3連複 | 1〜3着の組み合わせ（順不同） | 22.5% |
| 3連単 | 1〜3着を着順どおり | 27.5% |

控除率は JRA の実際の値に合わせています。オッズ計算に効くだけで、
プレイヤーから見えるのは最終的なオッズだけです。

### 枠

JRA と同じく、頭数に応じて 1〜8 枠へ割り振ります（8 頭以下なら 1 頭 1 枠、
9 頭以上は 8 枠に均等割りして、余りは**大きい枠から**足す）。出走は **8〜18 頭**です（複勝・ワイド・3連系が 3 着まで数えるため、8 頭以上が要ります）。
範囲外のレースは CSV 取り込み時に警告つきで落とします。既定は 12 頭です。

## レースの見立て

### 距離

**1 層 = 100 m** とします。

| モデル | 層数 | 距離 | メモリ(fp32) |
| --- | --- | --- | --- |
| llm-jp-3-150m（既定） | 12 | 1200 m | 約 0.7GB |
| llm-jp-3-440m | 16 | 1600 m | 約 1.8GB |
| llm-jp-3-1.8b | 24 | 2400 m | 約 7GB |
| Llama-3-8B | 32 | 3200 m | 約 32GB |

JRA の距離が 1000〜3600 m なので、この換算だとどのモデルでも実在しそうな距離に収まります。
**既定は 150m** で、CPU でも 1 レース数秒です。
層数はモデルによって違うので、**距離はレースごとに CSV から決まります**。

### 途中経過

各層で logit lens（その層の隠れ状態を出力埋め込みに通す）を掛けた確率を使います。
層 0 は入力そのもので意味がないので **層 1 から**使います。

## オッズの作り方

### 単勝

語ごとに設定した **オッズ平均 `oddsMean` と分散 `oddsVar`** から、対数正規分布で引きます。
正の値しか出ないので、オッズの分布として素直です。

```
σ² = ln(1 + oddsVar / oddsMean²)
μ  = ln(oddsMean) − σ² / 2
単勝オッズ = clamp(exp(N(μ, σ)), 1.0, 999.9)   … 0.1 刻みに丸める
```

この式は**モーメントマッチング**で、生成される値の平均がちょうど `oddsMean`、
分散が `oddsVar` になります。「平均 3.5 倍、そこそこブレる」といった指定がそのまま効きます。

### 他の券種

単勝オッズから逆算します。実際の馬券市場と同じ順序です。

1. **単勝オッズ → 市場の推定勝率**
   `q_i = 0.80 / odds_i` を正規化して `p̂_i`（合計 1）にします。
   ここが「人気」で、真の確率とは少しズレます。これがゲーム性になります。

2. **Harville モデルで的中確率を出す**
   1着が i、2着が j、3着が k になる確率を
   `P(i,j,k) = p̂_i × p̂_j/(1−p̂_i) × p̂_k/(1−p̂_i−p̂_j)` で近似します。
   「1着が抜けたあとは残りで同じ比率の争いになる」という単純な仮定です。
   券種ごとに必要な組を足し上げます（18 頭でも 3連単は 4,896 通りなので全列挙できます）。

3. **ランダム性を乗せる**
   `ε ~ 対数正規(0, σ_b)`（σ_b = 0.10）を掛けます。
   単勝から機械的に決まるだけだと妙味が無いので、券種ごとに少しズラします。

4. **控除率を掛けてオッズにする**
   `オッズ = 控除率_b / (P × ε)`

丸めは実際の馬券に合わせ、**10 倍未満は 0.1 刻み、100 倍未満は 1 刻み、
それ以上は 10 刻み**、上限 9999.9 倍です。

### 乱数の再現性

レースごとに**シードを持ちます**。同じシードなら毎回同じオッズになるので、
展示中に画面を作り直しても値が変わりません。テストもできます。
シードは CSV 取り込み時に自動で振られ、設定画面から振り直せます。

### 初期値を Colab 側で決める

オッズ平均・分散を 1 語ずつ手で入れるのは大変なので、ノートブックが初期値を出します。

```
oddsMean = clamp(0.80 / p_final, 1.1, 500)      … 控除率ぶんだけ甘い
oddsVar  = (0.18 × oddsMean)²                    … 変動係数 18%
```

**上位人気が実際に来やすい**設定です。そのままでも遊べて、荒れさせたいレースだけ
GUI で分散を上げる、という運用を想定しています。

## 順位変動をなめらかにする

logit lens の順位は層ごとに激しく入れ替わります。そのままだとレースになりません。
3 段階で対策します。

### 1. アプリ側の補正

各層の確率を対数（logit）にし、層方向にならしてから位置に変換します。

```
z_i(t) = (log p_i(t) − 平均_t) / 標準偏差_t      … 層ごとに標準化
s_i(t) = z の移動平均（窓 7、端は縮小）           … 層方向にならす
w(t)   = clamp((t − 0.5T) / (0.5T), 0, 1)²       … 後半ほど本命に寄せる
z̃_i(t) = (1 − w(t)) × s_i(t) + w(t) × z_i(T)
```

これを**速度**に変換します。位置を直接いじらないので、**馬が後ろに戻りません**。

```
v_i(t) = max(0.2, 1 + 0.25 × z̃_i(t))
A_i(t) = Σ_{u≤t} v_i(u)                          … 累積＝進んだ量
x_i(t) = A_i(t) / A_i(T) × X_i                   … 最後がちょうど X_i になるよう正規化
```

`X_i` は**ゴール地点**で、1着が距離そのもの、以下は最終 logit の差に応じて後ろに置きます
（1 logit あたり 20 m、最大で距離の 15%）。

この正規化がポイントで、**着順は必ず最終出力確率の順**になります。
途中は自由に入れ替わってよく、ゴールだけは正解と一致します。
「途中が正確な順番を反映していなくてよい」という前提をここで使っています。

窓の広さは実測で決めています。極端に荒れた入力を 30 本流したとき、
1 層あたりの順位変動の合計（10 頭）が窓 5 で 5.2、窓 7 で 4.6 でした。
これ以上広げると逆転そのものが減ってレースが単調になるので 7 で止めています。

### 2. ノートブックのグラフ

CSV を書き出す前に、**縦軸 logit** と**縦軸 probability** の 2 枚の順位変動グラフを出します。
極端に暴れるレースはここで気づけるので、プロンプトを変えるか層を間引く判断ができます。

### 3. GUI での確率編集

設定画面で層ごとの確率を直接編集できます。上の補正が入る前の値を触るので、
**「この語をもっと粘らせたい」といった調整**ができます。編集すると
その場でレースのプレビュー（順位変動グラフ）が更新されます。

## コースとアセット

### コース

**右回りの 2D オーバル**です。直線 2 本と半円のコーナー 2 つでできています。

```
                 第3コーナー ┌─────────────┐ 第4コーナー
                            │   向正面    │
                            │             │
                 第2コーナー └─────────────┘ 第1コーナー
                                 ゴール前直線
```

距離をトラック上の位置に変換する関数（`src/lib/track.ts`）が、
**進んだ距離 → 座標と向き**を返します。コーナーでは馬の向きが連続的に回るので、
ちゃんと回り込んで見えます。内枠ほど内側のレーンを走ります
（レーンごとに実距離が変わるのは煩雑なので、見た目だけです）。**レーンの間隔は頭数から決める**ので、
18 頭でも外ラチをはみ出しません。

周回数は距離とコース1周の長さから決めます（1周 1600 m 相当）。

### 馬

`src/player/assets/Horse.tsx` に SVG で描き起こします。外部画像を持たないので、
オフラインでもビルド成果物だけで動きます。

- **真上から見た図**。横から見た絵だと向正面で上下が逆さになってしまう
- 胴・首・頭・耳・四肢・尾・騎手のパーツで構成
- 脚と尾は CSS アニメーションで走らせる（`prefers-reduced-motion` では止める）
- 馬番と語のラベルは回転を打ち消して常に水平にする（回すと読めない）
- 語のラベルは団子のときに重なるので**上位5頭だけ**に出す
- 勝負服は枠番の色（JRA の枠色：白・黒・赤・青・黄・緑・橙・桃）

## 制作の流れ

```
ノートブック（notebooks/next_word_race.ipynb、ローカル or Colab）
  プロンプトを並べる
      ↓ logit lens で各層の確率を計算
  順位変動グラフ（logit / probability）を目視で確認
      ↓
  races.csv を書き出す（オッズ平均・分散の初期値つき）
      ↓
アプリの設定画面「コンテンツ」→ 馬券風予想
  CSV を取り込む
      ↓
  オッズ平均・分散・層ごとの確率を GUI で調整
      ↓
  プレビューで順位変動を確認
```

### CSV の形式

1 行が「あるレースのある語」です。

| 列 | 内容 |
| --- | --- |
| `race_id` | レースの識別子 |
| `race_name` | レース名（「第1R 今日は」など） |
| `prompt` | プロンプト |
| `model` | モデル名（画面に出す） |
| `word` | 候補の語 |
| `final_prob` | 最終出力の確率 0..1 |
| `odds_mean` | 単勝オッズ平均の初期値 |
| `odds_var` | 単勝オッズ分散の初期値 |
| `layer_1` … `layer_N` | 各層での確率 0..1 |

列の順序は問いません。`layer_` で始まる列を層番号の昇順に読みます。
UTF-8（BOM つきも可）で、ヘッダ必須です。

## データ構造

```ts
interface BettingEntry {
  word: string;          // 出走馬 ＝ 候補の語
  finalProb: number;     // 最終出力確率（着順の根拠）
  oddsMean: number;      // 単勝オッズ平均
  oddsVar: number;       // 単勝オッズ分散
  layerProbs: number[];  // 層ごとの確率（層1から）
}

interface BettingRace {
  id: string;
  name: string;
  prompt: string;
  model: string;
  seed: number;          // オッズ生成の乱数シード
  entries: BettingEntry[];
}

interface BettingContent extends ContentBase {
  type: 'betting';
  races: BettingRace[];
  startingMoney: number;   // 既定 100000
  raceCount: number;       // 既定 5
  refillPerRace: boolean;  // 既定 false
  metersPerLayer: number;  // 既定 100
}
```

`layerProbs` の長さがレースの層数で、そのまま距離になります。
レースごとに層数が違ってもかまいません。
